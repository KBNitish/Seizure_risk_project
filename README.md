AI-Assisted Seizure Detection & Emergency Response System

An IoT and AI-based system for monitoring health parameters, detecting possible seizure events, assessing seizure risk, and providing emergency alerts.

Features

* Real-time health monitoring
* Seizure detection and risk assessment
* Emergency alerts and location sharing
* Medication reminders
* Sleep and health tracking
* Seizure history
* AI/ML-based risk prediction

Tech Stack

* Hardware: ESP32 + Sensors
* Frontend: TypeScript
* Backend: Node.js
* Database: Amazon DynamoDB
* Real-time Streaming: Apache Kafka
* AI/ML: Python
* Version Control: Git & GitHub

Project Status

🚧 Currently under development.

Hardware and sensor configuration are completed. Software development and system integration are in progress.

Note: This is an academic/research prototype and is not intended for medical diagnosis or treatment.
